### 3.2 Үр дүн ба зөв байдал (Sudoku validator)

Sudoku-ийн хүчинтэй шийдэл бол мөр бүр, багана бүр, 3×3 дэд хүснэгт бүр 1–9 цифрийг яг нэг удаа агуулсан байх ёстой. Тест хийхдээ дараахыг хамруулна (даалгаврын нөхцөлтэй тулгаж тохируулна):

| Тест | Хүлээгдэх үр дүн | Бодит үр дүн |
|---|---|---|
| Зөв, бүрэн шийдэл | Хүчинтэй | |
| Нэг мөрөнд давхардсан тоо | Хүчингүй (аль мөр гэдгийг хэлнэ) | |
| Нэг баганад давхардсан тоо | Хүчингүй | |
| 3×3 дэд хүснэгтэд давхардсан тоо | Хүчингүй | |
| Бүх мөр, багана зөв боловч дэд хүснэгт буруу | Хүчингүй | |
| Хоосон эсвэл 0 агуулсан хүснэгт | Хүчингүй, ойлгомжтой мэдэгдэл | |
| 1–9-өөс гадуурх тоо, үсэг | Алдаа, crash гарахгүй | |
| Хэмжээ буруу (8×9, 10×10), файл олдохгүй | Алдаа, crash гарахгүй | |

Олон thread ашигласан бол: thread-үүдийн үр дүнг зөв нэгтгэж байгаа эсэх, race condition-гүй эсэх.

## 4. Review PDF-ийн бүтэц

Peer Review Guide §5-ын дагуу яг энэ дарааллаар:

| Хэсэг | Агуулга |
|---|---|
| Нүүр | Шүүмжлэгч код (IV-2-2), шүүмжилсэн код (IV-2-5), төсөл, огноо |
| 1. Ажлын ойлголт | Зорилго ба хэрэгжилтийг өөрсдийн үгээр |
| 2. Туршилтын орчин | OS, architecture, compiler/runtime, dependency |
| 3. Build/Run | Manual дагасан алхам ба үр дүн (§3.1) |
| 4. Туршилт | Үндсэн ба нэмэлт тестийн хүснэгт (§3.2) |
| 5. Дүрслэлийн үнэлгээ | Ажиллагаатай нийцэл, ойлгомжтой байдал (§3.3) |
| 6. Давуу тал | Нотолгоотой хоёроос цөөнгүй зүйл |
| 7. Асуудал | Priority, нотолгоо, нөлөө |
| 8. Сайжруулах санал | Асуудал бүрт хэрэгжүүлэх санал |
| 9. Дүгнэлт | Сайжруулах гурван гол зүйл |

Хавсралтад удирдамжийн "Хавсралт A. Review маягт"-ыг (Build / Run / Үндсэн тест / Нэмэлт тест × команд, хүлээгдсэн, бодит үр дүн; Priority × асуудал, нөлөө, санал) бөглөж оруулна.

**Priority:** Critical — үндсэн функц ажиллахгүй эсвэл буруу үр дүн · Major — гол тест, дүрслэл, Manual ноцтой дутуу · Minor — үндсэн ажиллагаанд саад багатай чанарын асуудал · Suggestion — нэмэлт сайжруулалт.

**Алдаа бичих дараалал:** Нөхцөл → Давтах алхам → Хүлээгдсэн үр дүн → Бодит үр дүн → Нөлөө → Сайжруулах санал. Жишээ нь "Дүрслэлээ сайжруул" гэхийн оронд: "Мөрөнд давхардсан 5 байхад Validate дарсны дараа самбар бүхэлдээ ногоон харагдсан. Буруу мөрийг улаанаар тодруулах саналтай."
